# agentes

Mod para o Claude Code que mostra, numa faixa acima do campo de mensagem, os agentes (subagentes) que o Claude está rodando. Cada agente aparece com um bonequinho animado em pixel art, a tarefa, o tipo e o modelo, a ferramenta que está usando agora, quantas ferramentas já usou, os tokens, o tempo e uma barra. Os concluídos ficam visíveis por alguns minutos e depois somem.
